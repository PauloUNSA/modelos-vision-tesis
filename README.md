# Modelos de Visión Artificial - Tesis

Repositorio con resultados de entrenamientos YOLO para detección de objetos (SH17 Dataset, reducción de 17 a 12 clases).

## Contenido
- Código, configuraciones y resultados de entrenamiento.
- Carpetas por modelo: `yolov9e/`, `yolo12n/`, `yolo12s/`, `yolo12m/`, `yolo12l/`, `yolo12x/`.

## Excluidos de este repositorio
Por límites de GitHub, no se suben los archivos `.pt` (pesas) ni `.zip` (paquetes de entrenamiento), ya que superan los 100 MB.  
Quedan disponibles localmente en esta carpeta y se pueden compartir por Google Drive, OneDrive o similar si se necesitan.

## Uso
Clonar el repositorio y cargar las pesas `.pt` con Ultralytics para inferencia o fine-tuning.
